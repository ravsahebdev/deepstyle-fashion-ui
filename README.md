# 🌸 deepstyle-fashion-ui

A modern fashion landing page built using HTML & CSS.

This project was created while practicing advanced frontend layout techniques including CSS Grid, Flexbox, positioning, and modern fashion inspired UI structuring concepts.

---

## 🚀 Features

- Modern Fashion UI
- Advanced Grid Layout
- Interactive Search Box
- Rotating Explore Circle
- Premium Card Composition
- Floating Decorative Elements
- Minimal & Aesthetic Interface
- Smooth Hover Effects

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Font Awesome
- Remix Icons
- Google Fonts

---

## 📚 Concepts Practiced

- display: grid
- grid-template-columns
- grid-template-rows
- gap
- display: flex
- position: relative
- position: absolute
- UI Structuring
- Grid Composition
- Alignment & Spacing
- Layering & Visual Hierarchy
